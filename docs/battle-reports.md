# 冒険に続けて読む戦闘結果

「今日」の前回の出来事に続けて、その日の戦闘を表示する。未挑戦なら「装備・スキル」で保存した8ターン分の行動で自動処理し、本文のあとに名前・技・対象・ダメージをターンごとに表示する。処理のタイミングは物語を開いたときで、夜間の締切処理ではない。

保存した結果は画面を開き直しても表示され、履歴の「戦闘結果を読む」からも開ける。章ボスの日も表示対象。報告データは認証済みプレイヤー自身のものだけを返す。

0010_battle_reports.sqlで保存用テーブルを追加した。報酬の二重配布防止を担うbattle_resultsとは分離し、敗北・時間切れは最新の試行を保存、勝利後は最初の勝利ログを保持する。勝利ログは報酬と同じDBバッチで記録する。再挑戦の直後はその試行の結果を画面に表示し、開き直したときは保存された勝利記録を表示する。

名前や装備が変わっても当時の内容を読めるよう、敵・パーティ・技も一緒に保存する。導入前の勝利には詳細ログが存在しないため、勝利済みと表示し、過去のダメージを推測で作らない。

自動処理は保存済みの敗北も再利用し、読み直すだけでは再戦しない。敗北後は装備・技の順番を見直し、「戦闘」から手動で再挑戦できる。その画面も保存済みの順番で初期化する。履歴も同じ自動処理・結果表示を使う。

依頼の再取得はバックグラウンドで行い、表示中の結果を消さない。保存順序の反映、同時リクエストでの報酬重複防止、敗北の再表示、プレイヤー間の分離、表示位置、通信失敗からの再読み込みをテストした。
