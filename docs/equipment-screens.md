# 装備・スキルと店

メニューから目的別に開く。

- 仲間：パーティの並べ替え・雇用・解雇・転職・ペット・アカウント復帰設定。
- 装備・スキル：仲間を選び、所持する武器・防具と習得したスキルを設定。それぞれの保存ボタンで確定する。
- 店：武器・防具の購入。購入後は「装備・スキルを設定する」から付け替える。

装備画面は `/api/me` のみで読み込める。店・酒場の取得に依存しない。保存中は仲間の選択と両設定をロックし、保存後も選択中の仲間ともう一方の未保存の設定を保つ。別の仲間へ切り替えると、その仲間の保存済み設定を表示する。

所持数、他の仲間の使用数、アクティブ6・パッシブ2の上限、既存APIのサーバ検証を継続する。データベース変更は不要。

検証：既存の購入・装備・パッシブ保持テストを対応画面へ移行。画面の分離、保存対象、保存後の選択保持、他の仲間の装備による制限、保存失敗時の選択保持を追加確認した。
