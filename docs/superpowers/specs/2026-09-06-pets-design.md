# 段階6 — ペット

## 1. いまの状態

イベントの結果に `petId` という口があり、`strayPuppy`（迷い犬）だけが `'puppy'` を返す。
**それを受け取る先がどこにも無い。** 犬を拾っても何も起きない。

最初の相談で挙がっていた3本柱のうち、職業とスキルは動いている。ペットだけが名前だけ残っている。

## 2. ペットとは何か

**戦闘に出る5人目ではない。** パーティは4人のままにする。

理由。5人目にすると、`simulate` に渡す面子が増えて戦闘のバランスを引き直すことになり、
闘技場20階まで実測で積んだ数値が全部やり直しになる。得るものに対して代償が大きい。

**ペットは世界に1匹、パーティ全体を底上げする存在**とする。

- プレイヤーごとに1匹だけ連れられる（複数手に入れても、連れるのは1匹）
- 効果は戦闘開始時から永続で、**パーティ全員にかかる**
- パッシブと同じ `Effect` 型で表す。新しい仕組みを足さない

これなら戦闘エンジンを一切変えずに済み、「連れ歩く相棒」という手触りも出る。

## 3. データ

`packages/core/src/data/pets.ts`（新規）。

```
Pet = { id, name, description, effect: Effect }
```

**8匹前後。** 効果は控えめにする。パッシブ2枠と足し合わさるので、
強い効果を置くとペットを持っているかどうかで難易度が割れる。

- 攻撃・防御・魔力・魔防・速度のいずれかを +10〜20%
- 被ダメージを -10% 程度
- 極端なもの（スタン耐性、特定属性の無効）は置かない。**壊れるより地味なほうがよい**

`turns` は永続を表す大きな値（既存のパッシブに合わせる）。

## 4. どう手に入るか

**非戦闘イベントの結果として。** `EventOutcome.petId` はすでにある口なので、それを使う。

- 既存の `strayPuppy` はそのまま `'puppy'` を返す
- **他のイベントにも `petId` を足す。** 8匹ぶんの入手経路を用意する
- 入手は世界の全員に配る。ルートが共有なので、得るものも共有（金貨と同じ扱い）
- **すでに持っているペットは重ねて配らない**

## 5. サーバ

```
player_pets   player_id, pet_id, obtained_at    ← 手に入れたペット
players       active_pet_id                     ← いま連れている1匹（NULL可）
```

- 締めのバッチで配る。**金貨の配布と同じ文の並びに入れる。**
  別のバッチにすると、金貨だけ入ってペットが入らない日が起こりうる
- 最初に手に入れた1匹は自動で「連れている」状態にする。
  手に入れたのに連れていない、が初期状態だと、拾った意味が伝わらない
- `POST /api/pet` — `{ petId }` で連れ替える。持っていないペットは断る
- `GET /api/me` に、持っているペットと連れているペットを足す

## 6. 戦闘への反映

`toPartyMember` はキャラ1人ぶんを組み立てる関数なので、ペットはその外で足す。

**サーバが戦闘を組み立てるときに、連れているペットの効果をパーティ全員の
初期効果として渡す。** 本編の戦闘と闘技場の両方に同じように効かせる。

`createBattleState` が初期効果を受け取れるようにする必要がある。
**これは `packages/core` への変更になる。** 受け取らない場合の挙動は今と同じにする
（既定は空）。

## 7. 画面

「仲間」の画面に足す。

- 持っているペットの一覧。名前・説明・効果
- いま連れている1匹を選ぶ
- **効果を数字で出す。** 「攻撃力 +15%」まで書く。曖昧にしない

## 8. テスト

1. 締めたときにペットが配られ、**二重に締めても重複しない**
2. すでに持っているペットは重ねて配られない
3. 最初の1匹は自動で連れている状態になる
4. 持っていないペットには連れ替えられない（認可を含む）
5. 連れているペットの効果が、**戦闘のパーティ全員にかかっている**
6. ペットを連れていない場合、戦闘の結果が従来と一致する（**後方互換**）
7. 闘技場でも同じ効果がかかる

**1・4・5・6 はガードや配線を外すと落ちることを確かめること。**
特に 6 は、ペットの仕組みを足したことで既存の戦闘が変わっていないことの検査。

## 9. やらないこと

- ペットのレベル・進化・餌
- ペットを戦闘の5人目として出すこと（§2の理由）
- 複数のペットを同時に連れること
