# 段階5 — 闘技場と裏ボス（エンドコンテンツ）

## 1. なぜ作るか

いまの遊びは**1日1回で終わる**。投票して、戦って、それで今日は終わり。
やり込みたい人の受け皿が無く、強くしたパーティを試す場も無い。

本編に終わりは作らない（そう決めた）。章は続く。闘技場はその横に常設し、
**いつでも挑める腕試し**として並走させる。

## 2. 本編との関係

| | 本編 | 闘技場 |
|---|---|---|
| 進み方 | 1日1歩。締めを待つ | いつでも、何度でも |
| ルート | 世界で共有（多数決） | 個人。誰がどこまで登ったかは別 |
| 報酬 | その日の戦闘で | **階ごとに初回のみ** |
| 討伐判定 | 誰か1人が倒せば世界として撃破 | 個人。肩代わりは無い |

**闘技場は本編を追い越す場にしない。** 報酬を階ごとの初回限りにすることで、
繰り返し挑んでも育成が進まないようにする。何度でも挑めるのは、
勝てるまで並びを組み替えるためであって、稼ぐためではない。

## 3. 構造

**塔。1階から順に上る。** 各階に1体。倒すと次の階が開く。

- **個人ごとに開く。** 他人が10階まで登っても、自分は1階からになる
- 開いた階には**いつでも戻れる**。報酬はもう入らないが、並びの練習になる
- **飛ばせない。** 1つずつ上る

### 3.1 階の数

**20階。** 最上階が裏ボス。

- 1〜5階: 冒険Lv3〜8想定。本編の第1章を進めていれば手が届く
- 6〜12階: Lv10〜20想定。転職と装備を使い分けないと勝てない
- 13〜19階: Lv20〜35想定。上級職と、覚えた技の持ち込みが要る
- 20階: 裏ボス

### 3.2 敵

**1階につき1体。戦闘エンジンは敵1体しか扱えない**（`simulate(party, enemy, plan)`）。
複数体を出すのはエンジンの変更になるので、この段階ではやらない。

**闘技場専用の敵を20体、新しく作る。** 本編の雑魚を数値だけ上げて使い回さない。
行動表がプレイヤーに公開される前提の遊びなので、**行動表が同じ敵は同じパズル**であり、
使い回すと20階ぶんの手応えが1階ぶんに縮む。

各階の敵は、**その階で問う型**を1つ持つ。

- 溜め→大技（窓に火力を集中させる）
- 一定ターンごとの全体攻撃（回復の置き方を問う）
- こちらの速度を下げる（行動順の読み替えを問う）
- 高い防御（貫通や固定ダメージ、能力スケールの持ち替えを問う）
- 属性耐性の偏り（属性を選ばせる）
- 激昂で行動表が変わる（前半と後半で別の解を要求する）

**同じ型を連続させない。** 隣り合う階が同じ問いなら、片方は要らない。

### 3.3 裏ボス（20階）

19階までをすべて倒した人だけが挑める。

**第1章のボスで成立しなかった「溜めの窓」のパズルを、ここで成立させる。**
20階に挑む頃には技が揃っており、窓に叩き込む大技を持っている。

- 行動表は2段階（通常・激昂）。両方を読んで組む必要がある
- 素朴な並びでは絶対に勝てないこと。**これを検査で保証する**
- 倒すと記録が残る。**最初に倒した人が誰かも残す**

## 4. データモデル

```
arena_progress   player_id, floor, cleared_at        ← 倒した階。1行1階
arena_first      floor, player_id, cleared_at        ← その階を世界で最初に倒した人
```

`arena_first` は世界ではなく**全体**で持つ。世界をまたいで「最初の1人」を残す。
`WHERE NOT EXISTS` で守り、二重に立たないようにする。

到達階は `arena_progress` の最大値から求める。列に持たない。
**持つと、行と食い違ったときにどちらが正か決められなくなる。**

## 5. API

`GET /api/arena` — いま挑める階、到達階、各階の記録、パーティ。
挑める階の敵の行動表を返す（本編と同じく隠さない）。

`POST /api/arena` — `{ floor, plan }`。

- 開いていない階は断る（到達階+1 まで）
- 勝ったら `arena_progress` に記録し、初回なら報酬
- **報酬の付与・進捗の記録・最初の1人の記録は同じバッチ**

`GET /api/arena/ranking` — 世界の全員の到達階。
**「みんなで」の遊びなので、個人戦でも他人がどこまで登ったかは見える。**

## 6. 画面

タブに「闘技場」を足す。5つになる。

- 塔の一覧。倒した階、いま挑める階、まだ見えない階
- 挑める階の敵の行動表と、本編と同じプランの表（**同じ部品を使い回す**）
- 到達階の一覧（他の人がどこまで登ったか）
- 裏ボスは、19階を倒すまで**名前も出さない**。何がいるか分からないほうがよい

## 7. 報酬

階ごとに初回のみ。金貨と経験値。**本編の同レベル帯より少し多い**程度に留める。
多すぎると本編を飛ばして闘技場で育てるのが最適になり、日々の投票が形骸化する。

裏ボスの報酬は金貨と経験値に加えて、**倒したという記録そのもの**。

## 8. テスト

1. 1階は最初から挑める。2階は1階を倒すまで挑めない
2. 倒した階には何度でも挑めるが、**2回目以降は報酬が入らない**
3. 到達階は `arena_progress` の最大値から求まる
4. **最初に倒した人の記録は上書きされない**
5. 19階を倒すまで20階に挑めず、**敵の情報も返らない**
6. 裏ボスは素朴な並び（一番強い技を撃ち続ける）では勝てない
7. 各階の敵が、想定レベルのパーティで勝てる（**実測**）
8. **隣り合う階の行動表が同一でない**（使い回しの検出）
9. 他人の進捗を書き換えられない（認可）

**2・4・5・9 はガードを外すと落ちることを確かめること。**

## 9. やらないこと

- 複数体との戦闘（エンジンの変更が要る）
- 時間制限や1日の挑戦回数制限（何度でも挑めることが前提の遊び）
- 闘技場専用の装備・報酬アイテム（装備品の仕組みがまだ無い）
