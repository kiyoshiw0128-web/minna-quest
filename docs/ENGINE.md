# エンジンの到達点

`packages/core` に何が入っていて、何が入っていないかの記録。
仕様書（`docs/superpowers/specs/2026-09-03-minna-quest-design.md`）は「こうする」と書いた文書で、
これは「こうなった」と書く文書。食い違ったらこちらが正しい。

最終更新: 2026-09-05（段階3bのマージ時点）
テスト: core 340件（戦闘9ファイル・育成10ファイル・日次9ファイル）

`packages/core` は実行時依存ゼロ。`Math.random` `Date.now` `crypto` を含まない。
時刻は引数で受け取り、乱数はシードから決まる純関数しかない。

## 1. 戦闘 `battle/`

### 完全に決定論

同じ入力からは必ず同じログが出る。乱数を一切使わない。命中率も会心も無い。
サーバが `simulate` の結果を正とし、画面は返ってきたログを再生するだけでよい。

行動順は実効速度の降順、同速ならID昇順。プレイヤーは戦闘前に順番を完全に読める。

### 事前セット方式

`BattlePlan` は「キャラID → ターンごとの技ID」の表。既定で8ターン分をすべて
戦闘前に決め、`simulate` が最後まで回す。途中の入力は無い。

プランの枠が空（`null`）なら「意図的に何もしない」、持っていない技を指していれば
`unknownSkill` として記録する。この2つはログ上で区別できる。壊れた／改竄された
プランをサーバが黙って受け入れないため。

### ダメージ

除算式。`基礎威力 × 100 ÷ (100 + 実効防御)`。減算式にしなかったのは、
防御が少し上がっただけでダメージが0に落ちて詰みが生まれるため。

4タイプある。

| 種別 | 決まり方 |
|---|---|
| physical | 攻撃力と威力から、防御力で割る。貫通率を指定できる |
| magical | 魔力と威力から、魔防で割る。貫通率を指定できる |
| fixed | 固定値。相手の防御を見ない |
| ratio | 相手の最大HPの百分率。上限値が必須 |

属性は6種（無・炎・氷・雷・聖・闇）。敵ごとに倍率を持ち、1.5なら弱点、0.5なら耐性。
最終ダメージは必ず1以上に丸める。

### 効果

3種類。ステータス変動（倍率）、被ダメージ変動、スタン。

**持続ターン数は速度に依存しない。** 付与されたターン番号を覚えていて、その同じ
ターンの終わりには減らさない。ここは一度壊れていた箇所で、覚えていないと
「遅い敵がかけた1ターンの効果は誰にも当たらないまま消える」という挙動になり、
仕様の目玉だった「溜め中の相手を狙う」戦術が成立しなかった。

どれだけ弱体化されても素の値の10%は残る。0や負の値にはならない。

### 敵

行動表を持つ。ターン数で割った余りの位置の技を使う。**この表はプレイヤーに
公開する前提**で、だから戦闘は運ではなく解けるパズルになる。

HPが一定割合以下になると別の表に切り替わる（激昂）。すでに倒れている敵は
激昂しない。死体の上で激昂するログを画面が再生してしまうため。

### 勝敗

敵の全滅を味方の全滅より先に判定する。相打ちはプレイヤーの勝ち。
8ターン以内に決着しなければ `timeout`。**キャラは死なない。** 負けても失うのは
その日の報酬だけで、ロストも巻き戻しも無い。

### 狙う相手

すべて決定論で決まる。5種類。相手側でHP割合が最も低い生存者、相手側の生存者全員、
自分側でHP割合が最も低い生存者、自分側の生存者全員、自分自身。同率ならID昇順。

## 2. 育成 `progression/`

### レベルが2種類ある

**冒険レベル**（上限50）は転職しても絶対に下がらない。その人物の地力。
**ジョブレベル**（上限30）は職業ごとに独立して持つ。就いたことのある職業だけが載る。

必要経験値は二乗で増える。冒険レベルが `60 × Lv²`、ジョブレベルはその半分の傾きで
`30 × Lv²`。ジョブ側を軽くしたのは、職業を試す敷居を下げるため。
1日1戦しか進まないので、後半のレベルは長期目標として機能する。

### 素質

7項目それぞれにA〜Eの等級を持つ。倍率は 1.3 / 1.15 / 1.0 / 0.85 / 0.7。

**素質はレベルごとの伸びにだけ掛かり、素の値には掛からない。** だから差はレベルが
上がるほど開いていく。低レベルのうちは素質の差がほとんど出ない。

### ステータスの式

```
素の値 + 冒険レベルの伸び × 素質 + 現在の職業の補正 × その職業のジョブレベル
```

第2項が転職で失われないので、転職しても弱くならない。

職業補正は引数で渡された職業のIDから引く。現在の職業とずれたまま呼ぶと
「パラディンの補正 × 戦士のジョブレベル」というどの職業にも対応しない数字が
黙って出るため、そうならない形にしてある。就いたことのない職業を渡せば
「その職業ならどうなるか」の試算がそのまま正しい値になる。

### 技の習得

ドラクエ方式。職業レベルが上がると、その職業の習得表にある技を覚える。
**覚えた技は転職しても永久に消えない。**

習得はレベルアップの時だけでなく、キャラ生成時と転職時にも走る。ここは一度
抜けていて、新品のキャラが初期職のレベル1の技を1つも持っていない状態になっていた。

### 職業

9種。基本6（戦士・武闘家・魔法使い・僧侶・盗賊・狩人）と上級3（パラディン・魔法剣士・賢者）。
上級職は前提となる職業のレベルで解禁する。

### 装備枠

戦闘に持ち込めるのはアクティブ技6枠とパッシブ2枠。習得済みの中から選ぶ。
覚えている技をすべて使えるわけではないので、ここが編成の選択になる。

### NPCも同じ型

主人公も雇用したメンバーも `Character` 型ひとつで表す。**雇ったNPCもプレイヤーが
転職させられる。** 特別扱いは無い。

戦闘用の型とは別物で、`bridge.ts` の `toPartyMember` だけが両者を繋ぐ。

## 3. 日次 `daily/`

### 1日は現実の1日

JSTの00:00で日付が変わる。開始日が1日目。時刻は必ず引数で受け取り、
エンジンが自分で現在時刻を読むことはない。壊れた開始日を渡すと例外を投げる。

締めるのはJST 05:00で、これはサーバ側（`apps/worker`）の仕事。

### 選択肢と投票

毎日3択を出す。シードが共通なので**全員が同じ3択を見る**。決定論なので
「なぜこの選択肢が出たか」を後から再現できる。候補が3つに満たなければあるだけ返す。

多数決で1つに決まる。同数ならシードで決める（タイブレーク）。
**締めは冪等。** すでに締まっている日は手を触れない。あとから票が増えても
確定した選択肢は動かない。

### イベント

出現条件を持つ。章の範囲、必要なタグ、禁止タグ。
選んだ結果は翌日の世界の状態に畳み込まれる（タグの追加、金、ペット）。
これが「毎日の選択で冒険が変わる」の実体で、通ったルートによって
その後に出る選択肢が変わる。

章は日数から決まる。イベントの結果では動かない。

### ボス

7日ごとが章ボスの日。1〜7日目が第1章。

### 酒場

日替わりで3人並ぶ。値段は冒険レベルに比例し、素質では最大2倍までしか上がらない。
**素質の高い低レベル人材のほうが安くなる。** 育てる日数がそのままコストになる形で、
デイリー制では日数が一番高くつくため。

### 乱数

シードと引き位置から決まる純関数。名前空間を3つに分けてある。
`:day:`（その日の3択）、`:tavern:`（酒場）、`:vote:`（タイブレーク）。
分けていないと、同じ位置を引いたときに票が割れる日と特定の選択肢が出る日が
相関してしまう。

## 4. 入っていないもの

エンジンにあるのは仕組みだけで、遊べる分量の中身はまだない。

| 何 | いまの数 | 位置づけ |
|---|---|---|
| 職業 | 9 | 骨格としては足りている |
| 技 | 14 | 職業9つに対して明らかに少ない |
| 敵 | 22 | 動作確認用。章ボスは1体だけ（バルゴス） |
| イベント | 10 | 3択を作るのがやっとの数 |
| パッシブ | 4 | 2枠に対して選択が生まれない |
| 名前 | — | 酒場の人物名のプール |

仕組みとして未着手のもの。

- **ペット** 型に `petId` の口はあるが、中身は無い
- **装備品** 武器も防具も無い。強さは職業とレベルだけで決まる
- **金の使い道** 雇用のみ。稼ぎと使い道の釣り合いは未検証
- **「誰かが倒せば世界としては撃破」の集約** サーバ側（段階3c）
- **報酬** 戦闘に勝った結果として何が入るかは未定義

## 5. 踏むと壊れるところ

- **`data/events.ts` は追記のみ。** 削除や並べ替えをすると過去の日の3択が変わる
- **`closeDay` に `daySeed` を渡さない。** タイブレークは `voteSeed`。型が同じなので防げない
- **効果の持続ターン数を「付与時に減らす」形に戻さない。** 速度依存に戻る
- **`computeStats` に現在の職業と違うジョブレベルを混ぜない**
